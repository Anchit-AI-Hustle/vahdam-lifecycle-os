Verdict: our stored data does NOT fully match the report

  • Live dashboard (trailing 12mo) $1.12M total is consistent with the report's ~$1.1M/yr run-rate, but it is a different scope, not the calendar-year table.
  • Historical shopify_analytics CSVs are wrong and appear synthetic: 2024 revenue overstated ~50 to 56%, 2023 orders off 44%, nonsense AOV column, coverage stops at 2025-03.
  • Cohort base uses the import-inflated 430,000 profile count instead of the report's 154,822 true purchasers.
  • All-time figures ($14.76M lifetime, 268,500 orders, 154,822 customers) had no representation in the repo until this transcription.
